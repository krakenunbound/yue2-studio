# YuE2 template thumbnails

Square illustrations for the Create template browser. The optimized 320×320 WebP files beside this document are used in the UI. Full-resolution PNG masters are kept in `full/` for larger views.

Every image used the same visual constraints: square editorial album-art thumbnail, one strong focal subject, rich cinematic lighting, readable at small size, no words, no lettering, no logo, and no watermark.
