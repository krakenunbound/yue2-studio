# YuE2 Studio logo

Generated with the built-in image-generation tool. The final transparent artwork is saved at `src/assets/yue2-logo-v2.png`; desktop icon sizes are generated with the Tauri icon utility into `src-tauri/icons`. The header uses a 40-pixel mark fully contained within its toolbar.

## Generation prompt

Create one polished minimal desktop application logo for YuE2 Studio. Actual transparent background, alpha channel. No enclosing square, no backdrop, no badge, no glow, no shadow, no text. A single bold graceful abstract Y that also reads as a musical tuning fork, using two elegantly curved cyan arms and a violet lower stem. Flat vector-like precise smooth silhouette, restrained cyan-to-violet coloring, simple enough to read sharply at 32 pixels. Balanced centered shape, generous transparent margin. Sophisticated professional audio software identity, not gaming, not neon 3D. Output one square transparent PNG.
